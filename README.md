核心设计
一、八维 = 4 对象 × 2 方向
八维不是 8 个独立设计，是笛卡尔积：
              外倾 e        内倾 i
  感觉 S        Se            Si
  直觉 N        Ne            Ni
  思考 T        Te            Ti
  情感 F        Fe            Fi
- 对象（S/N/T/F）问的是「处理什么」——接收端内容 vs 加工端内容
- 方向（i/e）问的是「从哪取」—— 已经沉淀的（L 层）vs 当下环境的（W 层）
一个洞察：「内倾者注意力聚焦」不是额外设定，而是方向的必然推论 ——
向内取（i）取的是已沉淀、整理过的内容，候选少，自然聚焦；
向外取（e）取的是当下未筛选的环境，候选多，自然发散。

为什么只分两层：物理分区该由生命周期决定 —— 而所有长期记忆的生命周期都是"沉淀 + 遗忘 + 持久化"，差异只在语义用途，那是查询条件，不是分库的理由。

四、内容标签与检索
每条内容四件事：是什么（role）、谁的（s_weight）、哪来的（origin / trigger）、多牢（strength / use_count）。
role:       [logic, value]    # 用途：推理依据 / 评价标准 / 待用素材
s_weight:   0.85              # 加工深度：1=照别人原话搬来，0=自己加工出来的
origin:     external          # 外部给的 / 我产的
trigger:    input             # 刚输入 / 从记忆翻出
strength:   1.0               # 巩固度
use_count:  0                 # 被调用次数
检索不靠目录，靠标签。 判断池只看 role，感知通道看 s_weight。
五、遗忘与沉淀
遗忘曲线是幂律（不是指数 —— 原方案的指数式拟合不上自身数据）：
R(t) = a₀ · t^(-β / strength)

  a₀ = 0.33 · β = 0.132 · t = 距上次调用的天数
只有「忘了」∧「从没用过」的才删：R < 0.2 且 use_count == 0。
沉淀有两条路，对应两种记忆方式：

「忘得快」不需要任何额外机制 —— 未加工的内容只能走 S 通道，
取用面窄 → 少被调用 → strength 不增长 → 自然衰减快。
整条链全部是既有规则的自然结果。
亮点
- 人格 = 参数。八个功能点位（Se/Si/Ne/Ni/Te/Ti/Fe/Fi），无总和约束。换一组数就是另一个人。
- 四型预设开箱可用：INTJ / INFP / ENTP / ESFP，含毕比模型字段（认知轴、互补、竞争、发展时序）。
- 会忘，也会记牢。幂律遗忘 + 巩固效应，常用内容衰减变慢。
- 两种记忆路径：理解过的记得牢，死记的忘得快 —— 不靠特判，靠机制自发产生。
- 会主动补给。依据不足时先翻自己的知识，再联网；失败时明说「依据不足」，不编造。
- 预载检验准则。一组「怎么判断」的通则（来源检验 / 证明强度 / 一致性 / 适用范围），不区分来源 —— 用户说的、自己记的、网上查的，走同一套检验。
- 不用扮演，也能像人。人格差异来自参数与记忆，而不是提示词的措辞。

SKILL.md §十四「术语纪律」值得一读 —— 它记录了这个项目踩过的一个坑：
八维的两个轴（方向 / 对象）同构且正交，命名稍有不慎就会互相污染。
结论是「结构约束强于行为约束」—— 靠命名规范，不靠人自觉。
理论基础
1. 八维 = 4 认知对象 × 2 方向 —— 笛卡尔积，不是 8 个独立设计
2. 聚焦 / 发散是方向的推论 —— 不是独立维度
3. 抽签决定倾向，容量决定预算 —— 两件不同的事
4. 存储分层由生命周期决定 —— 不是由内容类型决定
5. 人格差异来自参数差异 —— 不是来自「扮演」
6. 遗忘遵循幂律 —— 频繁使用 → 巩固度上升 → 遗忘变慢
三个保留假说：发展时序 · 互补性 · 竞争性（毕比模型的理论基础）
